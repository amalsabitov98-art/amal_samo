# Техническая спецификация: B2B-платформа онлайн-бронирования туров

Разбор платформы mir-jahon.uz (раздел online.mir-jahon.uz) как референса.
Документ описывает продукт, стек, роли, модули, модели данных, страницы,
флоу бронирования и правила.

Разбор основан на публичных страницах mir-jahon.uz (разделы экскурсионных
туров, путешествий, отелей, билетов, регистрации). Backend-логика
туроператора реконструирована по наблюдаемому поведению UI.

> **Как это соотносится с нашим кабинетом — см. §13 в конце файла.**

---

## 1. Что это за продукт

B2B туристический маркетплейс / система бронирования для туроператора.
Туроператор загружает инвентарь (экскурсионные туры, пакетные путёвки,
отели, авиабилеты), а турагентства регистрируются как организации и
бронируют этот инвентарь для своих клиентов по B2B-ценам (нетто/партнёрским).

Публичная часть (`/open/...`) доступна без входа — там можно смотреть
каталог и цены, но чтобы забронировать, нужно войти под аккаунтом
агентства. Классическая модель «туроператор → турагент», а не B2C.

Ключевые признаки B2B (а не B2C):

- Регистрация — это **заявка организации**: юр. название, бренд, лицензия,
  свидетельство о госрегистрации, ИНН, МФО, банк, р/с, ФИО директора, логотип.
- В карточке тура присутствует блок «B2B» и детальная разбивка цены на
  компоненты (партнёр, компания, страховка, транспорт, гид, билет, отель).
- Логин/пароль придумывает сам агент при регистрации; без них бронь
  недоступна («Брон қила олишингиз учун логин ва паролни ...»).

## 2. Технологический стек оригинала

| Слой | Определено | Признаки |
|---|---|---|
| Backend framework | PHP, Yii2 | `meta-csrf-param: _csrf`, `meta-csrf-token`, роутинг `/controller/action` (`/site/login`, `/open/default/registration`), путь ассетов `asset-cork/` (Yii asset bundle), AdminLTE-подобная вёрстка |
| Роутинг | Yii route `module/controller/action` | `/open/excursion-tours/index`, `/open/tours/index`, `/site/language?language=ru` |
| Frontend | Server-side rendered (Bootstrap 4 + jQuery), Font Awesome | классы `text-success`, `ml-2`, `fa fa-chair`, `text-warning` |
| Локализация | 4 языка: uz (кириллица/латиница), tr, en, ru | `/site/language?language=xx`, флаги |
| Валюты | мультивалютность с живым курсом ЦБ | `$ 1 = 12 005`, `€ 1 = 14 061` в шапке, обновляется |
| Интеграции | GDS для отелей и, вероятно, авиабилетов | «Бу бўлим халкаро GDS га уланган булиб, нархлар автоматик ўзгариши мумкин» |
| Оплата | QR-оплата | страница `/open/default/payment` + telegram.png, QR |

Yii2 воспроизводить не обязательно — важно повторить доменную логику и UX
(рекомендации по стеку — §11).

## 3. Роли и права

- **Гость** (`/open/*`) — видит каталог, цены, детали туров, формы поиска.
  Бронировать не может.
- **Турагент** (organization) — регистрируется как организация, входит по
  логину/паролю, бронирует, видит B2B-цены и разбивку, оформляет оплату.
  Основной пользователь.
- **Админ / туроператор** (backend, скрыт) — заводит направления, туры,
  даты заездов, отели, рейсы, цены, курсы валют, модерирует заявки агентств.
  В публичной части не виден, но спроектировать его нужно.

## 4. Карта разделов (навигация)

Верхнее меню (public):

1. **Экскурсион турлар** (`/open/excursion-tours/index`, `/open/default/index`)
   — экскурсионные туры / групповые заезды.
2. **Саёҳатлар** (`/open/tours/index`) — путешествия / динамические пакеты
   (перелёт + отель).
3. **Мехмонхоналар** (`/open/hotels/index`) — отели (подключены к GDS).
4. **Билетлар** (`/open/tickets/index`) — авиабилеты.

Служебные:

- `/` — главная
- `/open/default/about` — о нас
- `/open/default/registration` — регистрация организации
- `/site/login` — вход
- `/open/default/payment` — оплата (QR)
- `/site/language?language=uz|tr|en|ru` — смена языка

Хлебные крошки на каждой странице: Асосий (Главная) → Раздел → Подраздел.

## 5. Модуль 1 — Экскурсионные туры (главный, самый проработанный)

### 5.1 Уровень A — список направлений (`/open/excursion-tours/index`)

Сетка карточек-направлений (плиток) с фото. Каждое ведёт на `tours?id=<N>`.

| id | Направление |
|---|---|
| 5 | Турция |
| 17 | Бали / Малайзия / Сингапур |
| 11 | Таиланд |
| 20 | Кисловодск – Ессентуки (санатории) |
| 1 | Китай |
| 14 | Азербайджан |
| 10 | Инфо-тур (FAM trips) |

Плюс промо-баннеры (ведут на `tours?id=...`) и ссылка на YouTube-плейлист
«Порядок пользования системой и бронирования».

### 5.2 Уровень B — список туров направления (`/open/excursion-tours/tours?id=5`)

Заголовок: «В разделе ТУРЦИЯ доступно N турпакетов». Список туров, каждый →
`tour-details?id=<M>`.

Пример (Турция, 10 туров): Трабзон; Трабзон+Стамбул; Батуми→Трабзон;
Трабзон→Батуми; Стамбул+Трабзон; Волшебный Стамбул (без авиабилета);
Узунгёль+Трабзон; комби-тур Баку+Трабзон; комби Трабзон+Батуми+Баку;
Трабзон+Узунгёль+Стамбул.

### 5.3 Уровень C — детальная карточка тура (`/open/excursion-tours/tour-details?id=98`)

Самый важный экран. Состав:

**a) Выбор даты заезда (Саёҳат даври)** — выпадающий список периодов.
Каждый пункт содержит:

- диапазон дат: `31.07.2026 - 07.08.2026`
- длительность: `7 кеча` (7 ночей)
- индикатор свободных мест иконкой `fa-chair` с цветовым кодом:
  - `text-success` (зелёный) + `10+` / `20+` — мест много
  - `text-warning` (жёлтый) + `10` — мест мало
  - (подразумевается `text-danger` / нет мест — при 0)

**b) Выбор отеля (Меҳмонхона)** — выпадающий список отелей тура (у тура
несколько вариантов размещения, каждый со своей ценой).

**c) Авиабилеты** — таблица с колонками: Танланг (выбор), Ташувчи
(перевозчик), Юк (багаж), Жўнаш вақти (вылет), Келиш вақти (прилёт),
Давомийлиги (длительность). Один тур может иметь несколько вариантов
рейсов туда/обратно.

**d) Категории пассажиров (возрастные тарифы)**:

- Катта ёшлилар (взрослые) — 12+
- INF (младенцы) — до 2 лет
- CHD — 2–6 лет
- CHD — 6–12 лет

(в других модулях взрослый = 18+, дети 0–17 — возрастные пороги
настраиваемы на уровне тура/поставщика)

**e) Переключатель «с авиабилетом / без авиабилета»** (Авиабилетли /
Авиабилетсиз) — влияет на итоговую цену.

**f) Правила оплаты (payment policy)** — текст, зависящий от близости даты
заезда:

- Стандарт: 30% в течение 3 дней с брони + остальные 70% не позднее чем
  за 20 дней до старта.
- Если до заезда < 20 дней: 100% в течение 1 дня (24 ч) с момента брони.

**g) Итог (ЖАМИ) + блок B2B** + таблица «К оплате» с разбивкой цены по
компонентам: Ҳамкор (партнёр) | Компания | Суғурта (страховка) | Транспорт
хизмати | ГИД хизмати | Қўшимча ҳизмат (доп. услуга) | Чипта (билет) |
Мехмонхона (отель) | Овқатланиш тури (тип питания) | Хонадан кўриниш (вид
из номера) | Жами (итого)

**h) Кнопка «Брон қилиш»** (забронировать) — при клике без входа
редиректит/требует логин.

**i) Галерея фото тура** (много изображений из `/web/uploads/...`).

**j) Блок «Включено в тур» (Саёҳатга киритилган)**: авиабилеты, завтраки,
трансферы по программе, N ночей проживания, мед. страховка, N экскурсий.

**k) Блок «Дополнительные расходы» (Қўшимча ҳаражатлар)**: обед и ужин,
личные расходы, входные билеты в музеи/платные объекты.

**l) Блок «Информация» (Маълумотлар)**: ссылки на YouTube-обзоры
отелей/направления, предупреждения (например, «в отеле X запрещён алкоголь»).

## 6. Модуль 2 — Саёҳатлар / Путешествия (`/open/tours/index`)

Динамическое пакетирование (перелёт + отель) с формой поиска. Поля формы:

- **Қаердан** (откуда) — страна/город (напр. O'zbekiston → Toshkent).
- **Қаерга** (куда) — сгруппировано по странам: Турция (Стамбул),
  Азербайджан (Баку), ОАЭ (Дубай), Грузия (Батуми, Тбилиси), Таиланд
  (Пхукет, Паттайя).
- **Саёҳат даври** — период поездки (диапазон дат).
- **Шахслар сони** (кол-во туристов) — взрослые (18+) + добавление детей
  с точным выбором возраста 0–17.
- **Класс перелёта** — Первый / Эконом / Бизнес.
- **Категория отеля** — 1*–5*, общежитие/хостел, квартира, гостиница, мотель.
- **Меҳмонхона** — конкретный отель (автокомплит).
- **Трансфер** — без трансфера / индивидуальный / групповой (автобус).
- Кнопка **Қидириш** (Поиск) → выдача вариантов пакетов.

## 7. Модуль 3 — Отели (`/open/hotels/index`)

Подключён к международному GDS, цены обновляются автоматически. Форма поиска:

- **Саёҳат даври** — даты заезда/выезда.
- **Мамлакат** (страна) — полный справочник стран мира (~200, uz|ru названия).
- **Шаҳар** (город) — зависит от страны.
- **Категория** — Все / 1*–5* / общежитие / квартира / гостиница / мотель.
- **Меҳмонхона** — конкретный отель.
- **Хоналар ва туристлар сони** (номера и туристы) — мультиномерная
  конфигурация: для каждого номера свои взрослые (1–9) и дети (0–17 с
  точным возрастом).
- **Қидирув тури** (тип поиска): Все / GDS / CONTRACT — два источника
  инвентаря: GDS (динамический) и собственные контракты туроператора.
- Кнопка **Қидириш**.

## 8. Модуль 4 — Авиабилеты (`/open/tickets/index`)

Форма поиска авиабилетов:

- **Тип**: Барчаси (все) / Бориб-келиш (туда-обратно) / Фақат бориш (в одну
  сторону).
- **Қаердан / Қаерга** — аэропорты, сгруппированы по странам (Ташкент,
  Трабзон, Бангкок...).
- **Жўнаш санаси / Қайтиш санаси** — даты вылета и возврата.
- **Шахслар сони** — взрослые (12+), INF (до 2), дети 2–11 (точный возраст).
- **Класс** — Первый / Эконом / Бизнес.
- Кнопка **Қидириш**.

## 9. Сквозные механики (нужны во всех модулях)

- **Мультиязычность (i18n)** — uz/tr/en/ru, переключение через query-param,
  хранение выбора в сессии/cookie. Весь контент (названия туров, страны, UI)
  переводимый.
- **Мультивалютность** — базовая цена в одной валюте (вероятно USD),
  пересчёт по курсу; в шапке живые курсы USD/EUR к суму. Курсы обновляются
  (интеграция с ЦБ РУз или ручной ввод админом).
- **CSRF-защита** — токен в meta на каждой странице, проверка на
  POST-формах (бронь, регистрация, вход).
- **Возрастные тарифы** — везде разбивка пассажиров по возрасту с
  настраиваемыми порогами (INF/CHD/ADT), влияющими на цену.
- **Индикатор доступности мест** — цветовой (зелёный/жёлтый/красный) +
  числовой (`10+`, `20+`, `10`).
- **Правила оплаты и отмены** — зависят от близости даты заезда (депозит %
  + сроки доплаты).
- **Загрузка медиа** — фото туров/отелей в `/web/uploads/YYYY/MM/hash.jpg`,
  ссылки на YouTube.

## 11. Рекомендация по стеку (из исходного разбора)

Оригинал на Yii2/PHP, но воспроизводить его 1:1 не нужно:

- **Frontend**: Next.js (React) + Tailwind — SSR каталог, формы поиска,
  карточки туров, i18n через next-intl.
- **Backend**: NestJS (Node/TypeScript) или Laravel — REST/GraphQL API.
- **БД**: PostgreSQL (сложные связи туров/дат/цен), Redis для кэша курсов
  и GDS-выдачи.
- **Интеграции**: абстрактный слой `SupplierProvider` с реализациями
  `GdsProvider` (Amadeus/Travelport/локальный агрегатор) и
  `ContractProvider` (собственный инвентарь).
- **Оплата**: провайдер УзБ (Payme/Click/Uzum) + QR.
- **Файлы**: S3-совместимое хранилище для медиа.
- **Admin**: отдельная админ-панель для туроператора (CRUD
  направлений/туров/дат/цен/отелей, модерация агентств, курсы валют).

MVP-порядок сборки: (1) каталог экскурсионных туров + карточка + бронь под
логином → (2) регистрация/аутентификация агентств → (3)
мультиязык/мультивалюта → (4) отели через GDS → (5) авиабилеты → (6)
динамические пакеты.

> ⚠️ Эта рекомендация написана в предположении «собрать с нуля». У нас уже
> есть работающий кабинет на Workers + D1 со сданным ядром — см. §13.

## 13. Как это соотносится с нашим кабинетом

Наш кабинет (`amal_samo`, Workers + D1, задеплоен) уже закрывает ядро §5 —
самое сложное в этой спеке. Переписывать с нуля на Next.js + NestJS +
PostgreSQL смысла нет: атомарное списание мест, возрастные цены на дату
выезда, комиссии, журнал действий и выгрузка манифеста уже работают и
покрыты 79 интеграционными тестами.

### Уже есть у нас

| Из спеки | Где у нас |
|---|---|
| Роли гость/агент/оператор (частично) | `agencies.role` = `agency`/`operator` |
| Заезды с датой, длительностью, местами | `departures` (date_start, transport, capacity, seats_taken) |
| Индикатор мест | «занято 0/65» (числом, без цветового кода) |
| Возрастные тарифы INF/CHD/ADT | `departure_prices` (kind=child, age_from/age_to) + расчёт по возрасту на дату **выезда** |
| Младенцы не занимают место | `occupies_seat = 0` |
| Бронь с пассажирами (ФИО, ДР, паспорт) | `bookings` + `passengers` |
| Оплаты и остаток | `payments`, сводка «оплачено / долг» |
| B2B-цены и комиссия агентства | `tours.agency_commission`, фиксируется в брони |
| Скрытая операторская маржа | `tours.operator_commission` (агентству не отдаётся) |
| Админка туроператора | вкладки «Все брони», «Списки пассажиров», «Агентства» |
| Заведение/отключение агентств, смена пароля | `/api/admin/agencies/*` |
| Журнал действий (кто создал/менял/платил) | `booking_events` |
| Защита от перебора пароля | `login_attempts`, 8/логин + 25/IP за 15 мин |
| Выгрузка списка пассажиров | манифест + CSV с BOM для Excel |

### Чего нет — по возрастанию стоимости

**Дёшево, даёт много (данные частично уже есть):**

1. **Публичный каталог без входа** — сейчас за логином всё, включая
   просмотр. В спеке гость видит туры и цены, логин нужен только для брони.
2. **Уровень «Направление»** (Турция → 10 туров → заезды). Поле
   `tours.destination` уже есть, экрана нет.
3. **Контент тура**: галерея, «включено», «не включено», инфо-ссылки.
   Для KARADENIZ всё это уже собрано в `karadeniz-tour-info.md`.
4. **Цветовой индикатор мест** (зелёный 20+ / жёлтый ≤10 / красный 0).
5. **Правила оплаты со сроками**: 30% за 3 дня + 70% за 20 дней до выезда;
   при <20 дней — 100% за 24 ч. Сейчас оплата вносится вручную без дедлайнов.

**Средне:**

6. **Самостоятельная регистрация агентства** заявкой с юр. данными (ИНН,
   МФО, банк, р/с, лицензия, свидетельство, логотип, директор) + модерация
   `pending/approved/blocked`. Сейчас агентства создаёт оператор руками.
7. **Разбивка цены на компоненты** (страховка, транспорт, гид, билет,
   отель, питание, вид из номера). Сейчас одна цена + комиссия.
8. **Выбор отеля внутри тура** (несколько вариантов размещения со своей
   ценой) — у нас размещение только как тип (SGL/DBL/TPL), без отелей.
9. **Выбор рейса** (перевозчик, багаж, время вылета/прилёта,
   длительность) — у нас только `transport` = TZX/BUS.
10. **Переключатель «с авиабилетом / без»**.
11. **Мультиязычность** uz/tr/en/ru — сейчас только русский.
12. **Мультивалютность** + курс USD/EUR к суму — сейчас только USD.

**Дорого / под вопросом на MVP:**

13. **Отели через GDS** (Amadeus/Travelport) — отдельный модуль с кэшем.
14. **Авиабилеты** — отдельный модуль.
15. **Динамические пакеты** (перелёт + отель с поиском) — самый сложный
    модуль, требует и GDS, и правил пакетирования.
16. **Онлайн-оплата** (Payme/Click/Uzum + QR).

### Что стоит взять в первую очередь

Публичный каталог (1) + уровень направлений (2) + контент тура (3) +
цветовой индикатор (4) — это законченный сценарий «агент показывает тур
клиенту, потом бронирует», он не требует ни GDS, ни новых интеграций, и
опирается на данные, которые уже есть в репозитории.

Дальше — правила оплаты со сроками (5) и самостоятельная регистрация
агентств (6): и то и другое снимает ручную работу с оператора.

## 14. Карточка тура: разбор по скриншотам (обновлено)

Скриншоты живой страницы `ТРАБЗОН (Турция) (2026)` показали устройство
точнее, чем текстовый разбор в §5.3. Главное отличие от нашей карточки:
**у них конфигуратор, у нас прайс-таблица**.

### Их порядок шагов

1. **Период путешествия** — выпадающий список с поиском. Пункт выглядит
   так: `31.07.2026 - 07.08.2026 · 7 ночей · 🪑 10+`. Дата начала **и
   окончания**, длительность, остаток мест ведром с цветом.
2. **Отель** — второй выпадающий список, до выбора периода заблокирован.
   У одного тура несколько отелей (`Radisson Blu Hotel Trabzon 5*` и др.).
3. **Авиабилеты** — таблица появляется после выбора: чекбокс «Выбрать»,
   перевозчик с номером рейса (`CENTRUM AIR C63309`), багаж (`20 кг`),
   время отправления (`ТАШКЕНТ 05.08.2026 15:40`), время прибытия
   (`ТРАБЗОН 05.08.2026 17:45`), продолжительность (`4 часов 5 минут`).
   Две строки — туда и обратно.
4. **Счётчики пассажиров** по возрастам: `Взрослые (старше 12 лет)`,
   `INF (до 2 лет)`, `CHD (2-6 лет)`, `CHD (6-12 лет)`. Рядом сразу
   считается `2 x 1 295.2` и `2 590.4 $` — цена за человека и итог,
   **до ввода ФИО и паспортов**.
5. **Переключатель «С билетом / Без билетов»** — меняет итог.
6. **Параметры размещения** в панели отеля: `Виды еды` (BB) и
   `Типы номеров` — шесть вариантов от `Standard Land View with Balcony`
   до `Panoramic Suite with Sea View and Balcony`.
7. **Правила оплаты** — жёлтый блок прямо в карточке (текст в §5.3f).
8. **ОБЩИЙ** — итоговая сумма, рядом иконка Telegram.
9. Ссылка на отель, кнопка **БРОНИРОВАНИЕ**.
10. **Программа — не на странице, а двумя PDF** на скачивание: узбекская
    и русская («СКАЧАЙТЕ ПРОГРАММУ: 7 НОЧЕЙ ТРАБЗОН»).
11. Внизу три колонки с иконками: `В стоимость включено` /
    `Дополнительные расходы` / `Информация`. В «Информации» — ссылки на
    обзоры отелей и направления плюс предупреждения
    («В отеле Tilya Resort употребление алкоголя запрещено»).
12. Справа карусель фото и промо-баннеры. В шапке курсы валют.

### Чем это отличается от нашей карточки

| У них | У нас |
|---|---|
| Заезд выбирается в dropdown | Список заездов карточками с ценами |
| Дата начала **и окончания** | Только дата начала |
| Выбор отеля (несколько на тур) | Отелей нет вообще |
| Тип номера (6 категорий) + тип питания | Размещение как код DBL/TWIN/TRPL/SNG |
| Таблица рейсов с багажом и временем | Только `transport` = TZX/BUS |
| Переключатель «с билетом / без» | Нет, билет всегда включён |
| Счётчики по возрастам с ценой за человека | Сразу форма ФИО + паспорт на каждого |
| Правила оплаты в карточке | Нет |
| Программа — PDF | Программа по дням на странице |
| Курсы валют в шапке | Только USD |

### Что из этого делать, а что нет

**Можно сразу, данные есть:**

- **Дата окончания заезда.** `tours.nights` уже заполнено (7), конец
  считается как начало + ночи. Показывать `31.07 — 07.08 · 7 ночей`.
- **Правила оплаты** — чистый текст плюс арифметика от даты выезда,
  новых данных не нужно.
- **Счётчики пассажиров с ценой за человека.** Показать «взрослый —
  $970, ребёнок 5-10 — $700» и предварительный итог **до** заполнения
  паспортов: сейчас агент видит сумму только после ввода всех данных.

**Заблокировано данными от оператора:**

- **Отели и типы номеров.** В ведомости нет ни отеля на заезд, ни
  категорий номеров. В описании тура отели названы (Batumi View Luxury,
  Rhisos Gold Rize), но без привязки к заездам и без прайса по
  категориям. Наши DBL/TWIN/TRPL/SNG — это **вместимость номера**, а не
  его категория; смешивать нельзя.
- **Рейсы.** Нет ни перевозчика, ни номеров, ни времени по заездам —
  только пример одного перелёта в описании тура.
- **«С билетом / без билетов»** — нужен второй прайс. Сейчас цена одна,
  и билет в неё входит.
- **Ссылки в «Информации»** и фотографии — нет ни одной.

**Копировать НЕ нужно:**

- **Их возрастные градации** `12+ / 0-2 / 2-6 / 6-12`. У нас границы взяты
  из реальной ведомости: `inf 0-2`, `Chd 2-5`, `Chd 5-10` (и `5-11` до
  17.07). Подмена сетки под чужую напрямую поломает цены.
- **Программу в PDF.** У нас она структурированными данными — из этого
  при желании делается и страница, и печать, и PDF. Обратно из PDF уже
  никак.
- **Dropdown вместо списка заездов** — спорно. Агенту, который сравнивает
  даты и цены, таблица со всеми ценами сразу удобнее, чем выпадающий
  список по одному. Их вариант выигрывает, только когда у тура десятки
  заездов и обязательный выбор отеля.
