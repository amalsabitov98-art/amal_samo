# Что сделать с утра

Пошагово, по порядку. Всё, что можно было сделать без вашего аккаунта,
уже сделано — здесь только то, что требует ваших рук.

---

## 1. Проверить, что всё цело (5 минут)

```bash
git clone <репозиторий>
cd amal_samo
npm install -g wrangler
wrangler login                      # откроет браузер, подтвердите доступ
```

Затем одна команда:

```bash
./test/run.sh
```

**Что она делает.** Поднимает копию системы у вас на компьютере, с
отдельной пустой базой, и сама проделывает всё, что будут делать
агентства: заходит под паролем, бронирует, считает цену ребёнку и
младенцу, проводит оплату, отменяет бронь, пробует влезть в чужие данные
и подобрать пароль. Каждое действие сверяется с ожидаемым результатом —
таких проверок 79. В конце гасит копию за собой.

Боевую базу и сайт она не трогает вообще.

**Что должно получиться** — последние строки:

```
ИТОГО: 79 пройдено, 0 провалено

Всё в порядке — можно разворачивать (см. DEPLOY.md).
```

Если хоть одна проверка провалилась (`✗`), разворачивать не надо —
пришлите мне вывод, разберусь. Смысл прогона в том, чтобы поломку нашли
вы за минуту, а не агентство, которое не смогло забронировать.

## 2. Создать базу

```bash
cd worker
wrangler d1 create turon-tour
```

Команда напечатает `database_id`. **Впишите его** в `worker/wrangler.toml`
вместо `СЮДА_ID_ИЗ_КОМАНДЫ_d1_create`.

---

## 3. Сгенерировать пароли и наполнить базу

```bash
cd ..
python3 tools/build-seed.py > db/seed.sql
```

В консоль выведутся логины и пароли — **сохраните их сразу**, второй раз
показаны не будут. В самом файле только хеши.

Пароль оператора никому не давайте: под ним видны брони всех агентств,
все деньги и паспортные данные.

```bash
cd worker
wrangler d1 execute turon-tour --remote --file=../db/schema.sql
wrangler d1 execute turon-tour --remote --file=../db/seed.sql
```

### Если база уже была создана раньше

`schema.sql` создаёт таблицы через `CREATE TABLE IF NOT EXISTS`, поэтому в
существующей базе новые колонки сами не появятся, и наполнение упадёт с
`table tours has no column named description`. Сначала накатите миграции из
`db/migrations/` — **по одному разу каждую**, в порядке номеров:

```bash
wrangler d1 execute turon-tour --remote --file=../db/migrations/001-catalog-content.sql
```

`ALTER TABLE ADD COLUMN` в SQLite не умеет `IF NOT EXISTS`: при повторном
запуске команда упадёт с `duplicate column name`. Это ожидаемо и ничего не
портит — значит миграция уже применена.

## 4. Развернуть API

```bash
wrangler deploy
```

Запомните адрес из вывода, вида
`https://turon-tour-api.<ваш-субдомен>.workers.dev`.

---

## 5. Включить сайт

**Settings → Pages → Source → Deploy from a branch**, ветка
`claude/new-session-w4esua`, папка `/ (root)`.

Адрес будет `https://amalsabitov98-art.github.io/amal_samo/`.

---

## 6. Связать сайт с API

В `js/config.js`:

```js
window.TURON_CONFIG = { apiBaseUrl: "https://turon-tour-api.<субдомен>.workers.dev" };
```

В `worker/wrangler.toml` — закрыть API от чужих сайтов:

```toml
ALLOWED_ORIGIN = "https://amalsabitov98-art.github.io"
```

Затем:

```bash
cd worker && wrangler deploy
cd .. && git add -A && git commit -m "Connect the cabinet to the deployed API" && git push
```

---

## 7. Проверить на живом

1. Открыть сайт, войти под агентством — должны появиться заезды с ценами.
2. Забронировать тестового пассажира.
3. Войти оператором — бронь видна, список пассажиров выгружается в CSV,
   оплата проводится, в истории видно, кто что сделал.
4. Тестовую бронь отменить — места вернутся.

## Что мне нужно от вас, чтобы доделать остальное

**Квартальные бонусы** (50/100/200 продаж → $1000/$3000/$7000) не
сделаны: непонятно, что считать продажей — заявку целиком, каждого
туриста, только оплаченные или только состоявшиеся поездки. И считать
квартал по дате брони или по дате выезда.

**Вместимость заездов.** Сейчас у всех стоит 65 мест — это моя оценка по
максимальной загрузке в ведомости (64). У борта и автобуса она наверняка
разная. От этого зависит, когда закроется продажа.

**Японские туры.** Заведены с комиссиями (100/150/250/250), но закрыты
для брони: нет ни дат заездов, ни цен.

**Подтвердить границу детского тарифа.** В ведомости `Chd 5-11` сменился
на `Chd 5-10` среди сезона. Я считаю «не включая верхнюю»: по `5-10`
десятилетний платит взрослый тариф. Если задумано иначе — правится в одну
строку.

**Правила отмены.** Сейчас агентство может снять бронь в любой момент, и
места сразу уходят обратно в продажу. Нужен ли срок запрета перед выездом
и штраф за поздний отказ.
