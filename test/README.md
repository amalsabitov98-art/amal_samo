# Проверка бэкенда

Прогоняет воркер и базу по-настоящему — на локальной D1, а не на моках.
Запускать перед каждым деплоем.

Проще всего одной командой из корня репозитория:

```bash
./test/run.sh
```

Она поднимает воркер, готовит базу, прогоняет тесты и гасит воркер за
собой. Нестандартный порт: `PORT=8788 ./test/run.sh`.

Вручную, если нужно держать воркер запущенным:

```bash
npm install -g wrangler          # если ещё не стоит
cd worker

# пересоздать локальную базу (пароль всех учёток: turon2026)
../test/reset-db.sh

# поднять воркер
wrangler dev --local --config wrangler.local.toml --port 8787

# в другом окне
node ../test/api-test.mjs
```

Проверяется: вход и роли, изоляция агентств друг от друга, расчёт цены по
возрасту, что младенец не занимает места, права оператора, списки
пассажиров, оплаты и возвраты, заведение агентств, отмена с возвратом мест.

Боевое наполнение (`db/seed.sql`) генерируется со случайными паролями,
которые печатаются один раз при сборке. Переменная `TURON_SEED_PASSWORD`
существует только ради тестов — на бою её выставлять нельзя.

Тест не идемпотентен: он создаёт брони и агентство, поэтому перед каждым
прогоном базу надо пересоздавать через `test/reset-db.sh`. Воркер при этом
можно не перезапускать — он читает базу с диска.
