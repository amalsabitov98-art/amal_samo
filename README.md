# Turon Tour — система авторских туров

Веб-каталог авторских туров: поиск, карточка тура с календарём цен и
доп.услугами, полный флоу бронирования с данными туристов.

## Возможности

- Поиск туров по направлению/названию и дате заезда, отдельная вкладка
  экскурсий
- Карточка тура: программа по дням, отели по категориям, включено/не
  включено, документы для визы
- Выбор даты заезда, категории отеля, типа размещения и количества
  туристов с живым пересчётом итоговой цены
- Дополнительные экскурсии (обычный тур) или модули (тур-конструктор) —
  добавляются в стоимость по клику
- Медицинская страховка как отдельная опция
- Форма бронирования с данными на каждого туриста (ФИО, гражданство,
  паспорт) и отправкой заявки

## Источник данных

По умолчанию сайт работает на встроенных моковых турах
(`js/data.js`) — ничего разворачивать не нужно, всё уже видно на
GitHub Pages. Когда будете готовы вносить туры через Google Sheet вместо
правки кода — разверните `worker/` (Cloudflare Worker) и впишите его
адрес в `js/config.js`. Подробная схема таблицы и шаги — в
[`worker/README.md`](worker/README.md).

## Локальный запуск

Чистая статика, сборка не нужна:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html          # поиск туров + вкладка экскурсий
tour.html           # карточка тура и бронирование
styles.css          # общее оформление
js/config.js        # переключатель источника данных (моки / Worker API)
js/data.js          # моковые туры + слой доступа к данным
js/pricing.js        # расчёт итоговой цены бронирования
js/search.js        # логика страницы поиска
js/tour.js          # логика карточки тура и формы бронирования
worker/              # Cloudflare Worker: Google Sheets API ↔ фронт
```

## Деплой на GitHub Pages

GitHub Actions:

branch`**, ветка — рабочая/основная, папка `/ (root)`.
